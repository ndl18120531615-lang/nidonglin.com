# Twikoo 评论系统实现总结

## 架构原理

```
浏览器(国内)  ──→  twikoo.nidonglin.com  ──→  Vercel Serverless Function  ──→  MongoDB Atlas
     ↑                      ↑
  Twikoo JS            自定义域名（国内可访问）
  (zstatic CDN)        
```

**核心问题**：Vercel 默认域名 `*.vercel.app` 在国内被墙，导致 Twikoo 后端请求超时（`ERR_CONNECTION_TIMED_OUT`）。通过绑定自己的域名绕过封锁。

**关键点**：Vercel 只封默认域名，自定义域名不受影响。Cloudflare DNS + Vercel 自定义域名 + MongoDB Atlas 这个组合在国内完全可用，且全部免费。

---

## 数据流

```
1. 用户打开文章页
       │
2. 浏览器加载 twikoo.min.js（从 zstatic CDN，国内快速）
       │
3. JS 读取 HTML 中内嵌的配置：envId = "https://twikoo.nidonglin.com"
       │
4. 前端 JS 发 POST 请求到 https://twikoo.nidonglin.com/
       │
5. DNS 解析 → Cloudflare CNAME → Vercel 边缘节点 → Serverless Function
       │
6. Serverless Function 读写 MongoDB Atlas 数据库，返回评论数据
       │
7. 同时调用 twikoo.getVisitors() 获取浏览量并显示在页面
```

## 配置文件

### `src/config/commentConfig.ts`

```ts
export const commentConfig: CommentConfig = {
  type: "twikoo",
  twikoo: {
    envId: "https://twikoo.nidonglin.com",   // 自定义域名，国内可访问
    lang: "zh-CN",
    visitorCount: true,                        // 开启访问量统计
    jsUrl: "https://s4.zstatic.net/npm/twikoo@1.7.9/dist/twikoo.min.js",  // 国内 CDN
    cssUrl: "/assets/css/twikoo-custom.css",   // 自定义主题样式
  },
};
```

- `envId` 在 Astro 构建时会被内嵌进 HTML 的 `<script>` 标签
- 前端 Twikoo JS 读取 `envId` 决定向后端哪个地址发请求
- `visitorCount: true` 启用访问量统计，配合 JS 调用 `twikoo.getVisitors()`

## 代码修改

### `src/components/comment/Twikoo.astro`

#### 评论功能（已有，无需改动）

```js
// 初始化评论
twikoo.init({
  envId: config.envId,
  el: "#tcomment",
  path: getCurrentPath(),
  lang: config.lang,
});
```

#### 访问量统计（新增）

```js
function updateVisitorCount() {
  const visitorsEl = document.getElementById("twikoo_visitors");
  if (!visitorsEl) return;

  // 如果 Twikoo 库还没加载完，500ms 后重试
  if (typeof twikoo === "undefined" || typeof twikoo.getVisitors !== "function") {
    setTimeout(updateVisitorCount, 500);
    return;
  }

  twikoo.getVisitors({
    envId: config.envId,       // 后端地址
    urls: [getCurrentPath()],  // 统计哪个页面
    includeReply: false,       // 不含回复数，只要访问量
  })
  .then(function (data) {
    // 填充 #twikoo_visitors 元素
    visitorsEl.textContent = data?.[0]?.count ?? 0;
  });
}
```

#### 触发时机

| 场景 | 触发方式 | 说明 |
|------|---------|------|
| 首次加载 | `DOMContentLoaded` → `initTwikoo()` → `.then()` 中调用 | 评论初始化成功后获取访问量 |
| Swup 页面切换 | `content:replace` 钩子 → 重新 init → 延迟 300ms 调用 | 单页导航时刷新新页面访问量 |
| 自定义事件 | `firefly:page:loaded` → 延迟 300ms 调用 | 兜底方案，确保其他场景也能更新 |

## 后端部署

### Vercel 部署 Twikoo 服务端

1. 通过 Vercel 一键部署模板：
   ```
   https://vercel.com/new/clone?repository-url=https://github.com/twikoojs/twikoo/tree/main/src/server/vercel
   ```

2. 配置环境变量：
   | Key | Value |
   |-----|-------|
   | `MONGODB_URI` | `mongodb+srv://user:pass@cluster.mongodb.net/twikoo` |

3. 部署完成后绑定自定义域名：
   - Vercel 项目 → Settings → Domains → 添加 `twikoo.nidonglin.com`

4. 验证：访问 `https://twikoo.nidonglin.com` 返回 `{"code":100}` 即成功

### Cloudflare DNS

| 类型 | 名称 | 目标 | 说明 |
|------|------|------|------|
| CNAME | `twikoo` | `cname.vercel-dns.com` | 将子域名指向 Vercel |

### MongoDB Atlas

- 免费集群（M0），512MB 存储
- 国内可正常访问（未被墙）
- 需在 Network Access 中添加 `0.0.0.0/0` 允许 Vercel 函数连接

## 站点部署

### `wrangler.toml`

```toml
name = "ndl"
compatibility_date = "2026-06-01"
account_id = "56ee09a432..."

[assets]
directory = "./dist"
```

### 部署命令

```bash
pnpm build          # 构建站点到 dist/
npx wrangler login  # 首次需要浏览器授权
npx wrangler deploy # 部署到 Cloudflare Workers
```

构建时 `envId` 会被 Astro 内嵌到每个 HTML 页面的 `<script>` 中，所以每次修改 `commentConfig.ts` 都需要重新构建和部署。

## 总结

| 层面 | 做了什么 | 目的 |
|------|---------|------|
| 前端配置 | `envId` 改为 `twikoo.nidonglin.com` | 绕过 Vercel 默认域名被墙 |
| 前端 JS | 新增 `updateVisitorCount()` 函数 | 调用 `getVisitors()` 显示浏览量 |
| 后端部署 | Vercel 重新部署 Twikoo + MongoDB | 修复旧项目是 demo 页面而非 Twikoo |
| DNS | Cloudflare CNAME 记录 | 子域名指向 Vercel |
| 站点部署 | `wrangler deploy` | 把新构建的页面推上线 |
