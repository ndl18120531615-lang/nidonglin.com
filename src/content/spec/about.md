## 🛠️ 关于本站

- 使用 **Astro** 构建，主题用的是 [Firefly](https://github.com/CuteLeaf/Firefly)，它基于 [Fuwari](https://github.com/saicaca/fuwari) 二次开发。感谢两位作者的开源。
- 站点部署在 **Cloudflare Workers**，源码同时托管在 GitHub 和 Gitee 上。
- 评论系统使用 [Twikoo](https://twikoo.js.org/)，后端跑在 Vercel 上，数据存在 MongoDB Atlas。
- 站内文章除特别注明外均为原创，转载请注明出处。
